# GoalStake
GoalStake es una mini aplicación para MiniPay donde los usuarios crean retos personales o grupales respaldados con dinero real.
Los participantes depositan fondos en un pozo común y deben completar un objetivo dentro de un plazo determinado.
Si cumplen el reto, recuperan su dinero y pueden ganar recompensas adicionales.
Si fallan, pierden su depósito, que se distribuye entre los ganadores y la plataforma.
